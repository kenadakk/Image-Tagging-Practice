# Image-Tagging-Practice

This repository contains sample image-tagging and annotation data created using **CVAT (Computer Vision Annotation Tool)**. It serves as a practice project to demonstrate practical data annotation skills, XML dataset structures, and Git version control.

### Files Included:
- **`Kitchen.jpeg`**: Sample indoor scene image.
- **`Street.jpeg`**: Sample outdoor scene image.
- **`annotations.xml`**: Structured annotation export containing tag data.
